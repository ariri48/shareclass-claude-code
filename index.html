┌──────────────────────────────────┬────────────────────────┐
│             방법                 │         효과           │
├──────────────────────────────────┼────────────────────────┤
│ /clear 로 대화 자주 리셋         │ 쌓인 컨텍스트 제거     │
│                                  │ "새 주제 = 새 대화"    │
├──────────────────────────────────┼────────────────────────┤
│ /context 로 현재 토큰 확인       │ 지금 얼마나 썼는지     │
│                                  │ 어디서 새는지 파악     │
├──────────────────────────────────┼────────────────────────┤
│ 긴 파일은 범위 지정해서 읽기     │ "1~50번째 줄만 읽어줘" │
│                                  │ 전체 파일 로딩 방지    │
├──────────────────────────────────┼────────────────────────┤
│ 안 쓰는 기능은 꺼두기            │ 시작할 때 오버헤드     │
│                                  │ 줄어듦                 │
└──────────────────────────────────┴────────────────────────┘

비유: 책상 위에 서류를 계속 쌓으면 일을 못하잖아요?
      /clear는 책상을 깨끗이 치우는 것과 같습니다!

강사 멘트:

"이건 유료 사용자분들이 특히 꼭 아셔야 할 팁입니다. Claude Code를 오래 쓰다 보면 대화가 길어지면서 토큰을 많이 소모하거나 답변 품질이 떨어질 수 있어요. 새로운 주제를 시작할 때는 /clear로 대화를 리셋하는 습관을 들이세요. 그리고 /context를 치면 지금 토큰을 얼마나 쓰고 있는지 확인할 수 있습니다. 큰 엑셀 파일을 다룰 때도 '전체 다 읽어줘'보다 '1~50행만 읽어줘'가 훨씬 효율적입니다."

자주 묻는 질문

Q: Node.js가 뭔가요? 위험한 건 아닌가요?

A: Node.js는 프로그램을 실행시키는 엔진입니다. 전 세계에서 가장 많이 사용되는 안전한 도구이며, Claude Code를 돌리기 위해 필요합니다.

Q: npm이 뭔가요?

A: Node.js에 포함된 프로그램 설치 도구입니다. 앱스토어처럼 프로그램을 다운받아 설치해줍니다.

Q: 회사 보안 정책으로 설치가 안 돼요.

A: IT 보안팀에 "npm global 패키지 설치 허용" 요청이 필요할 수 있습니다. 교육 전에 미리 확인해주세요. 안 되면 교육 당일 보조강사가 도와드립니다.

Q: 기존에 쓰던 프로그램에 영향을 주나요?

A: 아닙니다. Node.js와 Claude Code는 독립적으로 설치되며 기존 프로그램에 영향을 주지 않습니다.

Q: 교육이 끝나면 삭제해도 되나요?

A: 네, 삭제 방법:


npm uninstall -g @anthropic-ai/claude-code
