Claude Code 설치

확인 방법

터미널(PowerShell 또는 터미널)을 열고 아래 명령어를 입력하세요.

claude --version

설치 명령어 실행

Windows — PowerShell을 열고 아래를 입력하세요.

irm https://claude.ai/install.ps1 | iex

Mac / Linux — 터미널을 열고 아래를 입력하세요.

curl -fsSL https://claude.ai/install.sh | bash
Node.js 등 필요한 것은 자동으로 함께 설치됩니다.
첫 실행 및 로그인

claude

Claude Code가 이미 설치되어 있다면, 대화창에 이렇게 말하면 끝!

winget install --id Git.Git -e

Dooray MCP 설치
Claude Code에서 Dooray를 쓸 수 있게 연결
확인 전

확인 방법

Claude Code 안에서 /mcp 를 입력하세요.

/mcp
dooray-mcp 가 connected 로 나오면 설치 완료!
소스 다운로드

터미널에서 아래를 한 줄씩 입력하세요.

cd $HOME\Documents git clone https://github.com/ariri48/dooray-mcp.git cd dooray-mcp
설치 마법사 실행
python setup.py
Dooray API 토큰 발급

setup.py가 토큰을 물어보면, 두레이에서 발급받아 붙여넣기 하세요.

발급 경로: 두레이 접속 → 좌측 하단 프로필 → 설정 → API 토큰 → 새 토큰 발급

토큰은 한 번만 보여줍니다. 복사해서 바로 붙여넣기 하세요.
연결 확인

Claude Code를 종료했다가 다시 실행한 후, /mcp 를 입력하세요.

/mcp

dooray-mcp가 connected로 나오면 성공!

교육 가이드 > 준비 > 1-G. MCP 소개 + 소스 다운로드 →
