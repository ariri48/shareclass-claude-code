NHN 사내 AI 서비스 활용 시 지켜야 할 보안 기준

← 교육 메인으로
⚠️
사내에서 AI 서비스(ChatGPT, Claude, Gemini, Copilot 등)를 업무에 활용할 때 지켜야 할 보안 기준입니다. AI 서비스에 직접 입력하는 텍스트뿐 아니라, AI가 화면을 읽거나 파일을 참조하는 경우에도 동일하게 적용됩니다.
🔒 AI 서비스에 입력하면 안 되는 정보
1. 개인정보

입력한 정보가 AI 학습에 활용되거나 외부 서버에 저장될 수 있으므로, 개인을 식별할 수 있는 정보는 입력하지 않습니다.

등급설명예시
RED 법령에 의해 암호화/보호가 의무인 정보 주민등록번호, 여권번호, 계좌번호, 카드번호, 비밀번호, 생체정보, 위치정보
ORANGE 개인을 직접 식별할 수 있는 연락처/민감정보 휴대폰번호, 이메일, 주소, 건강정보, 사상/정치견해, 범죄경력
YELLOW 단독으로는 식별 어렵지만 조합하면 식별 가능 이름+아이디, 기기식별정보(UUID/IMEI), MAC주소, DI
GREEN 단독 노출은 허용하나 조합 시 주의 이름, 아이디, CI, IP
✅
시스템 로그에 포함된 IP 등 개인 식별이 불가능한 정보는 개인정보에 해당하지 않습니다.
2. 영업비밀

외부 유출 시 회사에 손해를 끼칠 수 있는 기밀 자료는 입력하지 않습니다.

  • 전략기획 자료
  • 마케팅 전략/계획
  • 연구개발 자료
  • 미공개 재무 데이터
  • 내부 의사결정 문서
3. 크리덴셜 (인증정보)

시스템 접근에 사용되는 인증정보는 절대 입력하지 않습니다.

  • API 키, 토큰
  • SSH 키, PEM 파일
  • DB 비밀번호
  • 서비스 계정 인증정보
  • .env 파일 내용
🌐 브라우저 자동화 도구 사용 시 추가 고려사항

Playwriter 같은 브라우저 자동화 도구는 로컬에서 동작하지만, AI가 화면을 읽는 과정에서 화면에 표시된 정보가 AI 대화에 포함됩니다.

✅
안전한 경우
공개된 웹 페이지 탐색 / 민감정보가 없는 단순 폼 입력 자동화 / 로그인 후 구조/레이아웃만 확인하는 용도
⚠️
주의가 필요한 경우
사내 시스템(SSO 로그인 필요)에서 데이터를 읽는 경우 / 기안 시스템에서 금액/거래처 정보가 화면에 표시되는 경우 / 인사/급여/결재 시스템 등 민감정보가 포함된 화면 조작
권장 절차
  1. 자동화 대상 화면에 위 금지 정보(개인정보/영업비밀/크리덴셜)가 포함되는지 확인
  2. 포함된다면 소속 부서 보안담당자 또는 정보보호팀에 사전 확인
  3. 민감정보가 화면에 노출되지 않도록 필터링하거나, 해당 단계만 수동 처리
💻 코드 작성 시 보안 기준

AI를 활용해 코드를 작성할 때도 보안 기준을 지켜야 합니다.

항목규칙
API 키/비밀번호코드에 직접 쓰지 않고 .env 파일 + 환경변수로 관리
SQL 쿼리문자열 직접 조합(f-string) 금지, 파라미터 바인딩(?) 사용
위험 함수eval(), exec() 사용 금지
파일 경로사용자 입력을 경로에 직접 연결하지 않고, 상위 디렉토리 탈출 검증
📦 외부 공개 저장소(GitHub Public) 주의사항
  • PAT(Personal Access Token)를 코드/설정파일/메신저/메일에 평문으로 저장하거나 전송하지 않기
  • PAT 발급 시 만료 기한 90일 이내, 최소 권한 원칙 적용
  • 사내 IP, 내부 URL, 인증정보가 포함된 파일 커밋 금지
  • .git/config, .gitconfig에 토큰 노출 여부 점검
한눈에 보는 요약
공개된 기술 문서/매뉴얼 내용O 입력 가능
일반적인 업무 질문/코드 질문O 입력 가능
개인정보 (이름+연락처, 주민번호 등)X 입력 금지
영업비밀 (전략/재무/미공개 자료)X 입력 금지
인증정보 (API 키, 비밀번호, 토큰)X 입력 금지
사내 시스템 화면 (민감정보 포함 시)사전 확인 필요
💬
