Step 1. 설치
1
Claude Code 설치
Windows PowerShell
irm https://claude.ai/install.ps1 | iex
Mac / Linux 터미널
curl -fsSL https://claude.ai/install.sh | bash
설치 확인
claude --version
숫자가 나오면 성공
2
첫 로그인
터미널
claude
브라우저가 열리면 Google 계정으로 로그인
3
첫 대화 테스트
Claude Code > 프롬프트
안녕하세요
Claude가 답하면 성공
4
Git 설치
Claude Code > 프롬프트
Git 설치해줘
Claude가 알아서 설치합니다
설치 확인
git --version
git version 2.x.x 나오면 성공
5
Python 설치
Claude Code > 프롬프트
Python 설치해줘
Claude가 알아서 설치합니다
설치 확인
python --version
Python 3.x.x 나오면 성공
6
Dooray MCP 소스 다운로드
터미널 (Claude Code 아님, 일반 PowerShell/터미널)
cd $HOME\Documents git clone https://github.com/ariri48/dooray-mcp.git cd dooray-mcp
7
Dooray API 토큰 발급

두레이 웹 → 좌측 하단 프로필 → 설정 → API 토큰 → 새 토큰 발급

토큰은 한 번만 보여줍니다. 바로 복사하세요!

8
설치 마법사 실행 + 토큰 입력
같은 터미널 (dooray-mcp 폴더에서)
python setup.py
토큰 물어보면 붙여넣기 → 테넌트 ID는 Enter(기본값)
9
MCP 연결 확인

Claude Code를 종료했다가 다시 실행한 후:

Claude Code
/mcp
dooray-mcp가 connected로 나오면 성공!
Step 2. 실습
📖 교육 메인 페이지 바로가기 →
10
작업 폴더 만들기 + 실습파일 다운로드

바탕화면에 shareclass-실습 폴더를 만들고, 실습 파일 3개를 다운로드하세요.

📊 매출_데이터_2026년4월.xlsx
📧 메일_발송_명단.xlsx
📋 팀원_업무현황.xlsx

11
매출 분석
실습 폴더에서 Claude Code 실행
cd Desktop\shareclass-실습 && claude
Claude Code > 프롬프트
이 엑셀 파일 열어서 팀별 매출 합산하고 순위 매겨줘
12
주간보고 만들기
Claude Code > 프롬프트
매출 분석 결과로 팀장님께 보고할 주간보고 만들어줘
13
Dooray 태스크 생성
Claude Code > 프롬프트
내 개인 프로젝트에 "Claude Code 연결 성공 🎉" 태스크 하나 만들어줘
14
대시보드 만들기
Claude Code > 프롬프트
이 데이터로 Streamlit 대시보드 만들어줘
브라우저에서 localhost:8501 열리면 성공
